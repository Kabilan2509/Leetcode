## Sync Mechanism

This repository utilizes **LeetSync** to automate code tracking upon submission:
* **Source Code:** Contains original solution files submitted on LeetCode.
* **Performance Metrics:** Captures execution runtime and memory utilization statistics.
* **Problem Specifications:** Automatically embeds problem descriptions and constraints.
